# 🎫 Visit Tiket - Atlas Infra Systems

Aplikasi berbasis web untuk **membuat tiket kunjungan inspeksi unit** dengan sistem verifikasi token dan integrasi WhatsApp.

---

## 📋 Fitur Utama

| Fitur | Keterangan |
|-------|------------|
| 📝 **Form Kunjungan** | Isi data PIC, tujuan visit, tipe unit, zona, dan jumlah unit |
| 🗺️ **Pilih Zona** | 5 zona dengan harga berbeda (Jakarta Pusat, Selatan, Tangerang, Bogor, Luar Jabodetabek) |
| 💰 **Estimasi Biaya** | Perhitungan otomatis dengan biaya tambahan untuk unit > 5 |
| 💳 **Metode Pembayaran** | GoPay, DANA, Transfer Bank |
| 📱 **Integrasi WhatsApp** | Kirim detail tiket langsung ke Admin |
| 🔑 **Verifikasi Token** | Sistem token 8 karakter acak dengan masa berlaku 300 detik |
| 📥 **Download Tiket** | Unduh tiket sebagai gambar PNG |
| ✅ **Responsive** | Tampilan mobile-friendly (seperti aplikasi Gojek) |

---

## 🗺️ Daftar Zona & Harga

| Zona | Wilayah | Harga Dasar |

| **Zona 1** | Jakarta Pusat & Sekitar | Rp 250.000 |
| **Zona 2** | Jakarta Selatan, Timur, Barat | Rp 350.000 |
| **Zona 3** | Tangerang, Bekasi, Depok | Rp 500.000 |
| **Zona 4** | Bogor, Cibubur, Cileungsi | Rp 650.000 |
